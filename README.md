# Phone-catalog

Phone Catalog is a modern web application that showcases a catalog of **phones, tablets, and accessories** with a focus on usability and responsive design.
The project highlights product specifications and visual presentation, providing visitors with a clear and engaging browsing experience.
Its purpose is to demonstrate **React + TypeScript integration**, **SCSS modular styling**, and **responsive layout techniques**, serving both as a product showcase and a learning example for front‑end development.



## Technical Requirements

To run this project, you will need:
- **Node.js (version 18.x or newer)** – Required runtime for Vite, React, and modern build tools.
- **npm (version 9.x or newer)** – Package manager to install and manage dependencies.
- **Git** – For cloning the repository and version control.
- **Modern browser** – To view and test the application.


## Installation and Setup

1. **Clone the repository:**
  ```bash
   git clone https://github.com/Sertavr/phone-catalog.git
  ```

 2. **Navigate to the project directory:**
  ```bash
   cd phone-catalog
  ```

 3. **Install dependencies:**
  ```bash
   npm install
  ```

 4. **Start the local development server:**
  ```bash
   npm start
  ```


## Features

- **Product Catalog** - Browse phones, tablets, and accessories in a well-organized product catalog.
- **Product Details** - View detailed product information, including images, specifications, and prices.
- **Product Search** - Find products quickly using the built-in search functionality.
- **Filtering and Sorting** - Filter products and sort them based on different criteria.
- **Shopping Cart** - Add products to the cart, update quantities, and remove items when needed.
- **Favorites** - Add products to a favorites list to save them for later.
- **Responsive Design** - The application is fully responsive and works across desktop, tablet, and mobile devices.
- **Interactive UI** - Interactive buttons, navigation elements, product cards, and other components provide clear visual feedback.
- **Navigation** - Easily navigate between the catalog, product details, cart, favorites, and other sections.
- **Loading and Error** - States: Handle loading processes and unavailable data with appropriate UI states.

## 🛠 Technologies Used

**React & React DOM:**
Core library for building interactive user interfaces with reusable components.

**React Router DOM:**
Enables client‑side routing and smooth navigation between pages by updating the view dynamically **without full page reloads**, ensuring a fast and seamless user experience.

**React Transition Group:**
Adds animations and transitions to enhance user experience.

**TypeScript:**
Ensures type safety and maintainable code structure in React components.

**Bulma Framework:**
Modern CSS framework for responsive and clean design.

**SCSS & Sass Migrator:**
Used for modular styling and migration of Sass codebases.

**FontAwesome Free:**
Icon library for consistent and visually appealing UI elements.

**Classnames:**
Utility for conditional CSS class management in React components.

**Vite + @vitejs/plugin-react:**
Fast development server and bundler optimized for modern React projects.

**ESLint, Prettier & Stylelint:**
Tools for code quality, formatting, and style consistency.

**Cypress:**
End‑to‑end testing framework for reliable UI and integration tests.

**gh‑pages:**
Deployment tool for publishing the project to GitHub Pages.
